Instruktioner för Yootheme Pro / Joomla

Steg 1: Lägg till JavaScript i Joomla

I Joomla admin, gå till System → Global Configuration → Custom Code och lägg till:

<script src="https://dev-intra.falkenberg.se/integrationer/integration-koha-web/js/koha-shelf.js" defer></script>

Steg 2: Lägg till HTML-element i Yootheme Pro

I Yootheme Pro page builder, lägg till ett HTML-element och klistra in:

<div class="koha-shelf" data-shelf-id="1"></div>

Byt ut "1" mot det shelf-id du vill visa.

Steg 3: Anpassa (valfritt)

Du kan anpassa visningen med dessa attribut:

Attribut Värden Beskrivning
data-source shelf, latest Källa: shelf (bokhylla) eller latest (senaste inköp). Standard: shelf
data-shelf-id nummer Obligatoriskt för shelf. ID för bokhyllan
data-columns 2, 3, 4, 5, 6 Antal kolumner (standard: 3)
data-card-size small, default, large Storlek på korten (standard: default)
data-max-books nummer Max antal böcker att visa (slumpar om fler finns)
data-api-url URL API bas-URL (auto-detekteras normalt)

Exempel med alla alternativ:

<div class="koha-shelf"
     data-shelf-id="1"
     data-columns="4"
     data-card-size="small"
     data-max-books="12"
     data-api-url="https://dev-intra.falkenberg.se/integrationer/integration-koha-web">
</div>
